# Neural Networks

Two assignments from the MSc neural-networks course. The first is a
deep-learning exercise on images; the second asks whether a neural
network is actually the right tool on ordinary tabular data.

| Assignment | Topic | What is here |
| --- | --- | --- |
| [01-transfer-learning](01-transfer-learning/) | CNNs, transfer learning | A from-scratch CNN against VGG16 transfer learning plus fine-tuning, on Oxford Flowers 102 |
| [02-classifier-comparison](02-classifier-comparison/) | MLP vs classical models | An MLP benchmarked against KNN, decision tree, random forest and SVM over three OpenML datasets |

Each directory holds the code and the submitted report.

Between them they need `tensorflow`, `tensorflow-datasets`,
`scikit-learn`, `pandas`, `numpy`, `matplotlib` and `seaborn`.
