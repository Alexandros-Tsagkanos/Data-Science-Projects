# Optimization and Decision Analysis

Three assignments from the MSc optimization course, covering the three
branches it taught: unconstrained nonlinear optimization, linear
programming, and decision analysis under uncertainty.

| Assignment | Topic | What is here |
| --- | --- | --- |
| [01-line-search-and-newton](01-line-search-and-newton/) | Nonlinear optimization | Steepest descent and Fletcher–Reeves with Armijo backtracking on the Freudenstein–Roth function |
| [02-linear-programming](02-linear-programming/) | Linear programming | Seven LP case studies modelled and solved with PuLP |
| [03-decision-analysis](03-decision-analysis/) | Decision analysis | Five decision-tree case studies, with EVPI/EVSI and Bayesian revision |

Each directory holds the solution code, the LaTeX source of the report
and the compiled PDF.

## Common ground

All three reports are written in Greek and typeset with LaTeX. The
Python is standard scientific stack — `numpy`, `matplotlib`, `scipy`,
and `pulp` for the linear programs — with no project-specific packaging.

The figures in the reports are generated by the code rather than drawn
by hand, including the decision trees in assignment 3, which are built
from `matplotlib` patches.
